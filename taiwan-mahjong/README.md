# 大殺四方：台灣十六張麻將特訓

十二月回台灣打麻將前的練功工具。打開 `index.html` 就能用，不用安裝任何東西，手機也能用。

## 五個功能

| 分頁 | 做什麼 |
| --- | --- |
| **牌效** | 放進手牌（17 張要打牌、16 張等摸牌），算出每張打出去後是幾近聽、有幾張進張，排出最佳打法，並算下一張、幾巡內摸到進張或自摸的機率。可以記「場上已見」的牌，進張會扣掉；可以設定已吃碰幾組。 |
| **防守** | 「模擬牌局」：電腦四家照牌效打到有人聽牌，換你挑一張安全牌，或猜他聽什麼，再揭曉他的手牌和每張牌的危險度。「自己輸入」：輸入某家的河、吃碰和你看得到的牌，算他聽每張牌的機率、他已經聽牌的機率，以及你手上哪張最安全。 |
| **台數** | 擺出胡牌的手牌、胡的那張、吃碰槓、花，選自摸／放槍、門風圈風、連莊、海底槓上等狀況，算出台數明細和每家要付多少。 |
| **練習** | 「打哪張」：隨機 17 張手牌，選要打的牌，跟最佳解比對。「聽什麼」：隨機聽牌手，選出所有會胡的牌；清一色模式專練最容易算錯的多面聽。答對率存在裝置上。 |
| **小抄** | 可以改的台數表（照你家規則改，台數頁跟著算）、開打前要問的規則、底台比例怎麼影響打法、攻守要點、用語、牌桌禮儀。 |

## 規則與算法

- 胡牌：5 組（順子／刻子）＋ 1 對，共 17 張；另支援嚦咕嚦咕（七對加一刻）。
- 幾近聽用逐門拆解（萬、筒、條、字分開算面子、搭子、眼，再合併），對照暴力解法驗證過。
- 台數會試所有拆法，取台數最高的那一種；暗刻、獨聽、平胡的判斷跟胡的那張放在哪一組有關。
- 莊家台（莊家＋連 N 拉 N）只在莊家胡牌或莊家付錢時加上。
- 進張機率：用看不到的牌（牌牆加別人手上）算超幾何分布的「至少摸到一張」機率。
- 讀牌模型：從看不到的牌隨機組出 1,000 手「他可能的聽牌手」（照剩下的張數加權），他一直丟的那一門、他打過的牌和附近的牌都降低權重，再統計每張牌讓他胡的比例。
- 用 300 局模擬牌局驗證：照模型挑最安全的牌打，放槍率 0.7%，隨便打是 9.3%；模型前 5 名猜中他真的聽的牌約 4 成。
- 聽牌機率表來自 1,500 局電腦對打（不吃碰、照牌效打）。
- 預設台數是常見規則，例如門清自摸 3、平胡 2、碰碰胡 4、清一色 8、大四喜 16。每桌規則不同，在「小抄」改成你家的。

## 檔案

```
taiwan-mahjong/
├── index.html          頁面
├── style.css           樣式（亮色／暗色）
├── app.js              畫面與互動
├── engine.js           規則核心：牌、幾近聽、聽牌、牌效、機率、讀牌、模擬牌局、台數、算錢、出題
└── test/engine.test.js 測試
```

`engine.js` 不碰畫面，瀏覽器跟 Node 都能用：

```js
const M = require('./engine.js');
M.analyze(M.parse('13456m246779p3458s55z').tiles);   // 牌效
M.waits(M.parse('1112345678999m123p').tiles, 0);       // 聽哪些牌
```

代碼格式：`m` 萬、`p` 筒、`s` 條，`z` 字牌（1 東 2 南 3 西 4 北 5 中 6 發 7 白），`f` 花（1-8 = 春夏秋冬梅蘭竹菊）。

## 測試

```
cd taiwan-mahjong
npm test
```

需要 Node 18 以上，沒有其他相依套件。
